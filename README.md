# FreeUni-OOP-Assignments

This repository contains my individual assignment solutions, project implementations and coursework for the **Software Engineering** course (Spring 2026) at the **Free University of Tbilisi (FreeUni)**.

---

### 📌 Course Overview & Scope
This course provides an in-depth exploration of the Object-Oriented Programming (OOP) paradigm, concurrent programming, network communication, and backend web architecture built with **Java**.

* **Institution:** Free University of Tbilisi (FreeUni) — MACS
* **Language & Tech Stack:** Java, Swing GUI, MySQL/JDBC, Multithreading, Servlets, JSP, Web Sockets
* **Key Focus Areas:** OOP Design Patterns, MVC Architecture, Unit Testing, Concurrency & Synchronization, Database Integration and Network Protocols (HTTP/Sockets).

---

### 📂 Repository Structure & Topics

* **`assignments/`** — 5 Comprehensive Individual Homework Assignments
  * `assignment-01/` — Generics, Java Templates & Unit Testing Frameworks (JUnit)
  * `assignment-02/` — Encapsulation, Inheritance & Polymorphism Design
  * `assignment-03/` — GUI Development (Swing, Listeners), MVC Architecture & Relational Databases (SQL)
  * `assignment-04/` — Data Persistence with JDBC & Multithreaded Execution (Thread Interruption, Synchronization)
  * `assignment-05/` — Web Architecture: HTTP (GET/POST), Dynamic Pages, Java Servlets & JSP
* **`group-project/`** — End-to-End Multi-threaded Web Application
  * Full team implementation focusing on code review, Git workflows, database management and network communication via Sockets and Servlets.

---

### 🛠️ Key Topics Covered

1. **Object-Oriented Design & Testing:** Polymorphism, Inheritance, Encapsulation, Design Patterns, and Unit Testing.
2. **Graphical User Interfaces:** Event-Driven Programming with Swing and Model-View-Controller (MVC) separation.
3. **Database Integration:** Relational schema design, SQL querying, and Java Database Connectivity (JDBC).
4. **Concurrency & Multithreading:** Thread lifecycles, race conditions, synchronization locks, and GUI thread safety.
5. **Web Technologies & Networking:** HTTP protocol, Client-Server architecture, Java Servlets, JSP, Object Serialization, and Web Sockets.
